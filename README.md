A curated collection of **Data Structures and Algorithms** implementations in **Java**, designed for **technical interview preparation** and **algorithmic proficiency**.

## Repository Overview
The repository is organized by topic to reflect commonly tested interview patterns:

- **ArrayPrograms** – Core array problems and optimizations  
- **BinarySearch** – Standard and advanced binary search patterns  
- **BinarySearchOn2DArrays** – Binary search applied to matrices  
- **SortingTechniques** – Fundamental sorting algorithms  
- **StringPrograms** – String manipulation and pattern-based problems  

Each solution prioritizes correctness, efficiency, and clarity.

## Coding Standards
- Time and space complexity considered explicitly  
- Edge cases handled defensively  
- Clean, readable, and interview-ready Java code  
- Problem-solving patterns aligned with FAANG expectations
